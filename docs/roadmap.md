# REVACHOL 路线图

> 版本：v1.9.0 | 更新：2026-07-21

---

## 当前限制

| 项 | 说明 |
|----|------|
| 无前端路由 | 单页应用，无 URL 状态持久化（页面刷新后状态丢失） |
| 无 HTTPS | 本地开发 + Docker 映射均为 HTTP |
| 管理员凭据硬编码 | `js/config.js` 中明文存储，浏览器可见 |
| Vite dev server 部署 | 非生产级静态文件服务，无 gzip/缓存 |
| 测试覆盖不完整 | 仅 core/services/utils 有单元测试，UI 交互无覆盖 |

---

## 短期计划（v1.10.x — v1.12.x）

### 生产部署方案

- Vite build 输出静态文件 → Nginx 反向代理
- 前端 `/api/*` 请求通过 Nginx 转发到 backend 容器
- 静态资源启用 gzip + 缓存头

### 管理员凭据移至后端

- 前端 `config.js` 删除 `ADMIN_PASSWORD` 硬编码
- 后端新增登录校验端点，凭据通过环境变量注入
- 前端登录流程改为透传用户名/密码到后端

---

## 中期计划（v1.13.x — v1.15.x）

### 补充 UI 自动化测试

- 目录树拖拽、右键菜单功能测试
- 贴纸上传、拖拽、样式切换回归测试
- 可见性切换、访客/管理员模式切换测试

### 文章全文搜索

- 方案 A：SQLite FTS5 全文索引（需切到原生 SQLite）
- 方案 B：前端搜索索引（纯内存，适合当前 sql.js）
- [REVIEW] 方案 B 更适合当前 WASM 架构，无需改数据库层

## 长期计划
